## 🚀 Architectural Philosophy & Core Capabilities

I engineer **autonomous multi-agent architectures, real-time audio DSP engines, and resilient, high-concurrency systems**. Over the past 5+ years of mission-critical engineering, I focus on building systems that don't just run—they self-sustain, self-heal, and deliver tangible commercial output with **zero cloud waste**.

Instead of relying on fragile third-party SaaS APIs, I specialize in **radical FinOps and hardware optimization**: deploying quantised local models (Ollama / Metal acceleration), custom multi-agent feedback loops, fail-closed security guarantees, and sub-millisecond audio algorithms running directly in the browser and on bare metal.

- **🤖 Autonomous Multi-Agent Fleets & RAG**: End-to-end agentic pipelines, Model Context Protocol (MCP) server design, hybrid vector search (Dense + BM25), semantic distillation, and self-scheduling background daemons.
- **🎵 Real-Time Audio DSP & Canvas/WebGL**: Sub-millisecond browser pitch detection algorithms (YIN, autocorrelation), AudioWorklet multithreading, and 60+ FPS interactive music game engines.
- **🛡️ Reverse Engineering & Fail-Closed Security**: Binary and script reverse engineering, automated threat auditing (AgentShield / REA), AST traversal, and vulnerability surface reduction.
- **☁️ Bare-Metal Infrastructure & Cloud FinOps**: High-concurrency Linux clusters, PM2 process supervision, reverse SSH tunneling, DDoS mitigation, and sub-millisecond database tuning (PostgreSQL WAL).
- **💻 Production Full-Stack TypeScript/Python**: Scalable reactive web applications, Next.js 15 App Router, FastAPI, and strict type safety across all boundaries.
